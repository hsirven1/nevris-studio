Grid
Strict 12-column with visible hairlines. Text sits in 4–5 columns while display type breaks the margin. Asymmetry comes from column offsets, never from tilt or float.
Imagery
Editorial stills: one large product shot per project, cropped hard against a rule. Occasional negative-inverted plate for a project's own world.
Motion
Type sets itself. Lines rise into place with a mask, rules draw left-to-right, the highlighter sweeps once on entry. Nothing loops.
Navigation
No header bar. A fixed masthead row (Nevris · index · contact) at the top edge, plus a running section marker in the bottom-left gutter.
Project worlds
Each project is a spread: full-width numbered row that expands into its own colour ground and its own display size. Wilder stays paper, Juno inverts to ink, Léré takes a single saturated plate.
Wordmark
NEVRIS set in the serif, letter-spaced wide at rest; on scroll it compresses to a single N° mark in the corner. The wordmark is typeset, not drawn.
Distinctive
Reads as authored — a studio with an editorial voice rather than a product page. Ages well, prints well, hard to mistake for a template.
Borrowed
wibify.de — serif italic against a single acid accent as the only colour event. daynight.co.uk — oversized numbering and metadata as structure. morez.co — restraint: one idea per screen, generous air.

Grid
Edge-to-edge blocks with 1px seams, no page margin. Sections are stacked panels of unequal height; the seam grid is the composition.
Imagery
Big and physical. Devices, screens and objects photographed on flat colour, shadows kept. Screenshots are always inside something.
Motion
Mechanical: panels snap, colour fields wipe, the object rotates a few degrees on hover. Cursor-reactive but never floaty — no easing softer than a machine.
Navigation
A single orange utility bar pinned to the top, lowercase, no logo lockup fuss. Section jumping through a persistent thin index at the bottom.
Project worlds
Each project claims a colour field and a "product page" of its own — spec list, states, one hero object. Wilder orange, Juno bone, Léré black with a projected image.
Wordmark
nevris™ lowercase, tight, always small. It behaves like a stamp on hardware: same size everywhere, never enlarged, occasionally rotated on a section edge.
Distinctive
Positions Nevris as a maker of things rather than a service. The most confident and the most opinionated of the three; strongest for recruiters skimming fast.

Grid
Everything is a row. Two-column asymmetric split at the top, then full-width index rows that expand in place. Rhythm comes from row height, not from decoration.
Imagery
Contained plates, not full-bleed: one image per row, consistent aspect, so the studio's variety reads as a system. Project pages break the rule with one full-bleed shot each.
Motion
Rows expand and collapse; highlights draw on as if with a marker; status dots pulse once. Scroll-linked text reveals a phrase at a time, greying what is behind.
Navigation
A floating bottom capsule with the section index and Contact. No top bar at all — the page begins with the statement.
Project worlds
Row hue is the world. Open a project and its hue takes the whole page: Juno lavender, Wilder graphite, Léré a museum green. Same skeleton, different ground.
Wordmark
NEVRIS as a text label, always paired with a status dot. It can be highlighted like any other word — the identity is the system, not the logo.
Distinctive
Scales best. Adding a fourth or tenth project is one more row, and the Lab fits natively as a live list. Reads credible and current rather than staged.
Borrowed
sowieso.wero-wallet.eu — numbered sections and marker-highlighted words carrying hierarchy. daynight.co.uk — status and metadata as content. wembi.ai — floating capsule navigation instead of a header.
